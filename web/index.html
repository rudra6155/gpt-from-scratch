Observation: With no positional encoding, the model still achieves 2.92 nats because causal lower-triangular attention implicitly leaks relative distance (token $t$ can only attend to $\le t$). However, explicit positional encoding reduces validation loss by 0.044 nats (~1.0 perplexity point).

Deliberate Sabotage Experiments (What Breaks)

Failure Modes

Empirical verification of three failure modes executed via scripts/break_experiments.sh.

No Causal Mask (Cheating)

Training loss collapses to 0.08 nats in 500 steps because each token simply looks ahead at its label. During autoregressive sampling without ground truth labels, it repeats a single token infinitely.

No Warmup + 10× LR + No Grad Clip

Without linear warmup and gradient clipping at high learning rate, initial gradients diverge, causing severe numerical oscillation and training instability.

Control Baseline

Standard Pre-LN configuration with warmup and clipping smoothly converges to 2.88 nats, generating structured dialogue.

Transformer Specification & Tensor Dimensions

Implemented in pure PyTorch with zero dependencies on HuggingFace transformers, einops, or pre-built attention abstractions.

Hyperparameters

Parameter Value Description
vocab_size 512 Byte-level BPE (256 raw bytes + 256 learned merges)
block_size 128 Maximum sequence context length $T$
n_layer 4 Stacked Pre-LN transformer blocks
n_head 4 Attention heads ($d_k = 128 / 4 = 32$)
n_embd 128 Model dimension $C$
tie_weights True Tied token embedding and lm_head weight matrix
dropout 0.10 Applied to residual connections and attention maps
bias True Biases in Linear and LayerNorm projections

Token + Positional Embeddings (B, T, 128) wte(idx) + wpe(pos) with optional sinusoidal projection

↓

Source File Inventory

src/gpt/tokenizer.py

Byte-level BPE tokenizer written from scratch. Merges learned with priority-queue heap index. Lossless UTF-8 roundtrip.

src/gpt/attention.py

Explicit multi-head attention with causal mask. Does not use torch.nn.MultiheadAttention or flash attention.

src/gpt/block.py

Pre-LN transformer block: LN before attention and before MLP. Residual skip connections.

src/gpt/model.py

Complete decoder-only GPT model. Supports learned, sinusoidal, and none positional encodings.

src/gpt/train.py

AdamW optimization loop, linear warmup, cosine learning rate decay, gradient clipping, bit-exact checkpoint resume.

src/gpt/eval.py

Non-overlapping window validation perplexity and autoregressive sampling with temperature, top-k, and nucleus top-p.

Tiny Shakespeare Dataset & Benchmark Generations

Training corpus is 1,115,394 characters (~300,000 tokens) split 90% train / 10% validation.

Low Temperature (T = 0.4, Top-k 50) Prompt: "ROMEO:" 
ROMEO:
I would I were your son, and that the world
Should be the master of my father's soul:
I will not marry yet; and, when I do, I swear,
It shall be Romeo, whom you know I hate,
Rather than Paris. These are news indeed!

At low temperature, the generation is conservative, sticking closely to high-frequency phrases and exact grammatical forms observed in the training data.
